# AI Use and Reflection (Lab 3)

**LLM Used:** Google Deepmind's Antigravity (Advanced Agentic Coding)

## Key Prompts Used
1. *"Can you help me write the login API using JWT so it's secure?"*
2. *"Can you help me format the reviewer.md file for my documentation?"*
3. *"Write some backend tests for the new Admin user management endpoints."*
4. *"How do I run the test suite to get the passing screenshots?"*
5. *"Can you build the IT Staff Ticket Queue page using the Zen Green design from the UI specs?"*
6. *"Help me draft the api-spec.md for the Internal Notes feature so Requesters can't see them."*
7. *"Why isn't my 'Problem Appears Resolved' button working right on the frontend?"*
8. *"Can you check my partner's github repository for the PRs I reviewed?"*

## My Reflection

Using the AI agent for Lab 3 was super helpful, especially for setting up the authentication and user roles since there was a lot of boilerplate code. The agent did a great job migrating the database and writing the backend tests for the new Admin features. It also made drafting the specification documents much faster.

However, I realized I couldn't just blindly trust the AI. Sometimes it got confused about the exact order of the PDF requirements or missed some of the pull requests in my partner's repository. It was a great helper for writing code and fixing bugs, but I still had to double-check its work and guide it to make sure we followed the assignment rules correctly.
